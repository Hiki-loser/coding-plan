### 口径说明

- **月额度**：由各供应商公开的套餐说明折算成 token 数，带 `~` 前缀的为人工测算值，可能与官方口径有偏差。
  同一套餐下不同模型消耗额度的速度不同，所以额度与单价都不同；给的是**单模型**额度，不是可叠加总量。
- **包月价 / 活动价**：包月价是刊例价，活动价是当前生效价。**没有活动时两者同值**（表示「按原价」而非「无数据」）。
- **¥/亿 tokens**：当前生效价 ÷（月额度 ÷ 10⁸），越低越划算。「正常」列用刊例价，「活动」列用当前生效价，
  无活动时两列同值。活动到期由读取层自动回退正常价，不需要改数据。
- **活动标签**：`首月` = 首月优惠，`限时` = 限时活动。
